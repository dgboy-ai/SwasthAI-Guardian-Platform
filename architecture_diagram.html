DIFFERENTIATOR 3 — AUTONOMOUS OUTBREAK AGENT (LAYER 1 — ACTIVE DETECTION)
Closed-loop AI agent — no human trigger — runs every 30 minutes
Every 30 min: OutbreakAgent queries Aurora symptom clusters → Groq Llama-3.3-70b (JSON mode, 3-attempt exp backoff)
If LLM confidence ≥ 70%: check DynamoDB 24h dedup → POST /api/admin/outbreak-alert → DynamoDB write → SSE broadcast → Live Map update

Agent Architecture

  • AGENT_SECRET env guard — fails loudly at startup if missing
  • Dynamic districtId: getDistrictId() Aurora join pre-write
  • Atomic UpdateCommand (patches 4 fields, no race condition)
  • Idempotent ensureTTL() — safe on every service restart

Trigger Threshold + Notifications

  • Example: 5+ fever cases in one village within 24h
  • DynamoDB: outbreak_telemetry write (villageId+detectedAt)
  • village_node_state: state='outbreak' → map red indicator
  • SSE: Admin dashboard Outbreak Radar live update + reasoning
